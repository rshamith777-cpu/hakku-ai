COMMUNITY SUPPORT · STATUTE CORRECTIONS · SECURITY REPORTING

1. Open-Source Community & Bug Reports

Hakku is maintained as an open-source citizen welfare technology project. If you notice an updated government circular, an altered eligibility ceiling, a broken portal URL, or a software bug, please open an issue on our GitHub repository:

github.com/rshamith777-cpu/hakku-ai

2. Responsible Security Disclosure

If you identify a security vulnerability, cryptographic weakness, or privacy issue, we welcome responsible disclosure. Please file a GitHub Security Advisory on the repository with steps to reproduce.

3. Citizen Grievance Assistance

If an authorized GramaOne, KarnatakaOne, or CSC counter refuses to accept an eligible welfare application or demands an unlawful fee above ₹30, citizens have the statutory right to escalate immediately:

  • Sakala Guarantee Helpline: Toll-Free 1902 (₹20/day delay compensation)
  • Janaspandana Grievance Portal: ipgrs.karnataka.gov.in
  • Central Govt Grievance (CPGRAMS): pgportal.gov.in
